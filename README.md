# JAX Motor Dashboard

명세 v1.0 기반의 반응형 UI 프로토타입입니다. 실제 하드웨어나 CAN/API 연결 없이 브라우저에서 모터 동작을 시뮬레이션합니다.

## 실행

```sh
npm run dev
```

http://localhost:5173 에서 확인합니다. Python 3가 필요하며 별도 패키지 설치는 없습니다.

- 모터 6개 중 2개 온라인, 모터별 입력값 및 마지막 전송값 관리
- 숫자 입력, 0.1° 증감, 슬라이더 동기화 및 ±15° 검증
- 전송 후 Moving → Reached 상태 시뮬레이션
- 긴급 정지 즉시 모든 모터 동작 및 입력 차단, 수동 해제
- 오프라인 모터 선택 및 연결 끊김 알림
- 반응형 레이아웃과 키보드 입력 지원

`npm run check`로 JavaScript 구문을 검사합니다.
