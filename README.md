# JAX Control Panel

Team JAX의 로봇 제어 UI 프로토타입입니다. AK45 4개와 STM32 서보 10개를 한 화면에서 관리하고, 제공된 JAX V2 URDF로 목표 자세를 미리 확인합니다. Foxglove의 패널 기반 구성을 참고했습니다.

## 실행

```sh
npm run dev
```

http://localhost:5173 에서 확인합니다. Python 3와 최신 WebGL 지원 브라우저가 필요합니다. 실행 시 패키지 설치나 인터넷 연결은 필요하지 않습니다. Three.js 0.180.0과 로더를 `dist/vendor/three`에 포함했습니다. 의존성을 다시 설치할 때는 `npm ci`를 사용합니다.

## 사용 순서

1. 왼쪽에서 모터를 선택합니다. 이름이나 ID로 검색하고, 그룹을 접거나 펼칠 수 있습니다.
2. 오른쪽 **3D 관절 연결**에서 실제로 대응하는 URDF 관절을 직접 선택합니다. 대응표가 제공되지 않아 기본값은 모두 미연결입니다. 관절 연결 전에도 목표 각도를 입력할 수 있으며, 3D 반영과 명령 전송은 관절 연결 후 가능합니다. 한 관절을 여러 모터에 중복 연결할 수 없습니다. 설정은 현재 브라우저에 저장됩니다.
3. 목표 각도를 입력합니다. 숫자, ± 버튼, 슬라이더가 동기화되고 파란색 목표 모델에 즉시 반영됩니다. 아직 모의 명령은 전송되지 않습니다.
4. **설정한 각도로 이동**을 누르면 모의 명령을 전송합니다. AK45는 모의 현재 각도가 이동하며, 서보는 전송 완료와 실제 위치 미확인을 표시합니다.
5. **현재 / 목표 / 겹쳐 보기**로 비교합니다. 연결된 관절은 3D 클릭으로 모터를 선택할 수 있습니다. 미연결 관절은 이름만 안내하고 모터 선택은 하지 않습니다.

## 구현 범위

- AK45 4개 / STM32 10개, 이름·ID 검색, 그룹 접기, 선택 동기화
- 실제 URDF 관절 계층, 원점 변환, 회전축, DAE 시각 메시를 사용하는 3D 모델
- 카메라 회전·이동·확대, 시점 초기화, 전체 화면, 관절 툴팁과 선택 강조
- 현재 / 목표 중첩, 관절별 각도 제한, 전송 전 미리보기 및 목표 초기화
- AK45 각도·전송 목표·속도(ERPM)·전류·온도·오류 상태와 4개 모의 그래프
- 그래프 휠 확대·초기화·값 확인·표시 선택·전체 화면
- 여러 모터 목표 미리보기 및 모의 전송 (원자적 하드웨어 동시 제어가 아님)
- 긴급 정지 시 모든 모의 이동 중단 및 제어 잠금, 해제 후 자동 이동 재개 없음
- 모의 연결 끊김·모터 오류·전송 실패 테스트, 지속적인 모터 오류 표시, 한글 알림
- 모바일 반응형 구성

패널 위치·크기 커스터마이징, 제어 이력, 강화학습 정책 표시는 P2 후속 범위입니다.

## 데이터 구분

**실제 통신 및 모터 구동은 구현하지 않았습니다.** 모든 연결 상태와 AK45 피드백은 모의 데이터입니다. ERPM 값 역시 시각화용 모의 값이며 기계 회전 속도에서 환산한 값이 아닙니다.

STM32 서보는 실제 각도·속도·전류·온도 피드백을 생성하지 않습니다. PWM 펄스폭 변환 규칙도 제공되지 않아 **정보 없음**으로 표시합니다. 회색 모델에서 서보 및 미연결 관절은 URDF 기준 자세이며 실제 관측 자세가 아닙니다. 연결이 끊긴 AK45의 제어 패널은 마지막 각도를 보여주고, 3D 관절은 기준 자세로 표시합니다.

관절 연결 전에는 ±15°의 임시 범위를 표시하되 목표 각도 입력은 허용하고 전송만 차단합니다. 연결 후에는 URDF 제한을 도 단위로 변환해 입력 범위에 적용합니다. 이 범위가 실제 하드웨어의 안전한 제어 범위라는 의미는 아닙니다. 모터 번호와 URDF 관절의 실제 대응은 운영자가 확인해야 합니다.

웹 긴급 정지는 시뮬레이션용 UI이며 하드웨어 비상 정지 장치와 별개입니다.

## 모델 출처 및 재생성

사용자가 제공한 `Downloads/URDF_1006/JAXV2_Assembly_description`의 모델입니다. 원본 URDF와 16개 DAE 시각 메시가 `dist/models/jax/`에 포함됩니다. 충돌 메시와 ROS 실행 설정은 브라우저 시각화에 사용하지 않습니다.

```sh
python3 scripts/import-model.py /path/to/JAXV2_Assembly_description
```

원본 URDF에서 링크, 관절, 변환, 회전축, 각도 제한을 읽어 `model.json`을 생성합니다. Collada의 Z-up 변환을 URDF 좌표계에 맞춰 처리합니다. Three.js의 MIT 라이선스는 `dist/vendor/three/LICENSE`에 포함되어 있습니다.

## 검증

```sh
npm run check
npm test
```

상태 로직 테스트는 입력과 전송 분리, 서보 피드백 미생성, 각도 범위, 긴급 정지, 연결 끊김·오류·전송 실패, 목표 도달, URDF 자산 및 각도 제한을 검증합니다. 관절 연결 누락 시 전송 차단과 도→라디안 변환, 실제 URDF 관절 회전에 따른 하위 링크 위치 변화도 검증합니다.
